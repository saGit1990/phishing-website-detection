this project focuses on developing an end to end solution that aims to detect network phising attempts based on domain indicators and behavorial pattern. The solution mimics safe search used by popular browsers like chrome, also explores its productionalisation using MLOps tool and cloud native optimization

Webthread detection system for phishing attack / PHISHING WEBSITE DETECTION PLATFORM
    Problem Statment: 
        Phishing websites are one of the largest causes of financial fraud worldwide. Attackers create visually identical websites to steal sensitive information. Manual blacklisting based method fail to detect newly created such websites. Therefore, an automated ML based real time phishing detection system is required to analyze URL, domain, SSL, traffic and behavioral features to prevent fraud at scale.
